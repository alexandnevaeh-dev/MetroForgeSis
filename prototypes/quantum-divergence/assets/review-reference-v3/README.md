# Mine-wall reference for isolated animation review

This image is the unchanged, normalized Quantum v3 SDXL/Pixel Art XL mine-wall candidate previously retained for static technical review. It is a reference backdrop for the original Diver animation fixture, not approved terrain, collision artwork, or the final biome background. The verifier records its SHA256 separately from the sprite manifest.

The SDXL base and Pixel Art XL model weights retain their separate Open RAIL++-M and CreativeML Open RAIL-M terms. No model weights are included here. Source generation, isolation and rejected actor findings are described in `docs/development/QUANTUM_ART_PIPELINE.md` at the repository root.
