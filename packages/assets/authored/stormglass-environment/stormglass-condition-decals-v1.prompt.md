# Stormglass condition decal atlas v1

Generated 2026-09-30 as a transparent 4x4 pixel-art atlas for the side-view Stormglass Reliquary test game.

The atlas contains sixteen isolated Gothic environment clusters: intact castle altar/banner/sconce/statue; flooded undercroft waterline/arch/roots/puddle; collapsed archive bookcase/books/rubble/balcony; and frozen bell-tower bell/gears/icicles/window. It uses the existing navy stone, oxidized teal, old brass, crimson, and ice-blue palette. The source prompt required transparent padding, no text, no backdrop, no characters, and distinct cells suitable for automatic extraction.

The normalized runtime files are produced by `scripts/extract-stormglass-condition-decals.mjs` in `condition-decals-v1/`.
